# PhotoPro Pro — نسخه ارتقایافته

این پروژه یک PWA دوربین موبایل با رابط حرفه‌ای است و برای تبدیل به APK آماده شده.

## قابلیت‌ها
- دوربین جلو و عقب
- فوکوس لمسی روی پیش‌نمایش
- زوم: 0.5× / 1× / 2× + اسلایدر در صورت پشتیبانی دستگاه
- نمایش رزولوشن و وضعیت دوربین
- نسبت‌های 4:3، 16:9 و 1:1
- گرید ترکیب‌بندی
- تایمر 3، 5 و 10 ثانیه
- فیلترهای زنده
- تنظیم روشنایی، کنتراست و اشباع بعد از ثبت
- پنل کنترل ISO / Shutter / EV / WB / Focus
- تلاش برای استفاده از قابلیت‌های واقعی Camera API دستگاه مثل zoom، exposure compensation، torch و focus mode
- گالری موقت داخل برنامه برای عکس‌های گرفته‌شده در همان اجرای برنامه
- انتخاب عکس از گالری دستگاه
- ذخیره JPG با کیفیت بالا
- PWA آفلاین با Service Worker
- رابط Liquid Glass واکنش‌گرا و فارسی

## نکته مهم درباره کنترل‌های حرفه‌ای
مرورگر موبایل اجازه نمی‌دهد روی همه گوشی‌ها کنترل‌های واقعی ISO، سرعت شاتر، RAW یا White Balance دستی را اجبار کنیم. کنترل‌های واقعی فقط وقتی اعمال می‌شوند که Camera API، مرورگر و سخت‌افزار آن گوشی آن قابلیت را ارائه کنند. این نسخه برای قابلیت‌های قابل‌دسترس، از getCapabilities/applyConstraints استفاده می‌کند.

## ساخت APK با موبایل
1. فایل‌های این پروژه را روی هاست HTTPS قرار بده؛ دوربین در محیط امن بهتر کار می‌کند.
2. آدرس PWA را در PWABuilder وارد کن.
3. بخش Android را باز کن و پروژه/بسته Android را بساز.
4. بسته خروجی را طبق ابزار ساخت به APK یا AAB تبدیل/دریافت کن.

برای انتشار فروشگاهی، signing key اختصاصی برنامه را نگه‌داری کن و application ID را قبل از انتشار ثابت انتخاب کن.

## تست
برای تست روی گوشی، با مرورگر Chromium/Android باز کن و اجازه Camera را بده.
